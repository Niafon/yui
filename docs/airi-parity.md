# AIRI parity

Сравнение с [moeru-ai/airi](https://github.com/moeru-ai/airi) (README и
дорожная карта на октябрь 2026). «Было» — до 0.4.0, «стало» — после.

## Интеграции

| Возможность | Состояние |
|---|---|
| Discord / Telegram | каркас интеграции (`integrations/discord`, `integrations/telegram`) |
| Minecraft / Factorio | каркас игрового bridge |

Игровые и сетевые интеграции намеренно не включаются без endpoint/token:
каждая команда проходит через реестр инструментов, риск и подтверждение.

## Где Yui сильнее

Приватность (журнал передачи данных, согласие на категории, локальный режим
по умолчанию), адаптивный выбор модели под нагрузку/игры, подтверждение
опасных действий, сопряжение телефона, шифрование чувствительных полей.

## Не сделано (и почему)

- **Click-through только по прозрачным пикселям** (как в AIRI): сейчас окно
  пропускает клики целиком. Попиксельный режим требует опроса курсора из Rust
  и чтения альфы WebGL-кадра — отложено.
- **Третьи языки интерфейса**: словарь устроен так, что язык добавляется
  новой колонкой в `i18n.ts`.

## Готовые библиотеки, на которые заменён самописный код

| Было | Стало | Зачем |
|---|---|---|
| RMS × 7 → один параметр «рот» | `wlipsync` (MIT, порт uLipSync) | распознавание гласных, а не громкости |
| `textContent` для ответов | `markdown-it` (html: false) | списки, код, ссылки без XSS |
| — | `fflate` | распаковка Live2D `.zip` (8 КБ вместо JSZip) |
| энергетический порог | `@ricky0123/vad-web` (Silero VAD v5) | различает речь и шум; ~16 МБ WASM/модели грузятся только при включении |
| `localStorage` для файлов | `idb-keyval` | хранение импортированных моделей (десятки МБ) |
| `removeUnnecessaryVertices` | + `VRMUtils.combineSkeletons`, `combineMorphs` | меньше draw-вызовов и морф-таргетов на кадр |
