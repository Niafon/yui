# Комплект для проверки — 5 сентября 2026

## Запуск на ПК

Откройте **`D:\yui\Start-Yui.cmd`**. В окне запуска нажмите **Включить ядро**.
Эта кнопка запускает процесс Yui Core в фоне; браузер автоматически не открывается.
Когда появится «Ядро включено и готово к работе», нажмите **Открыть интерфейс**.
Если ядро уже работает, второй экземпляр не запускается. Воркеры запускаются
по существующей конфигурации ядра. Закрытие окна запуска не выключает ядро.
Журналы запуска: `.cache/core-launcher.log` и `.cache/core-launcher-error.log`.
Остановка фонового экземпляра — `powershell -ExecutionPolicy Bypass -File scripts\stop-check.ps1`.
Прежний консольный запуск доступен через `scripts\start-local.ps1`; он останавливается Ctrl+C.

Первый запрос загружает LLM и поэтому медленнее следующих. Модель и нагрузка
видны во вкладке **AI Runtime**. Auto предпочитает 9B на свободной GPU;
Gaming может использовать 4B CPU. CPU-профиль 9B тоже установлен.

Веса — `models`, llama.cpp — `bin/llama`, ядро — `bin/yui-core.exe`,
интерфейс — `desktop/dist`, Python-зависимости — `.venv`.
В локальной конфигурации только локальные провайдеры. После установки
модели работают без интернета.

## Телефон: клиент с вычислениями на компьютере

1. Подключите телефон к той же домашней сети.
2. Передайте на телефон публичный сертификат **`data/tls/yui-ca.crt`**, например
   по USB, и установите его как доверенный CA. Файлы `.key` остаются на ПК.
   На iPhone после установки профиля также включается доверие сертификату;
   названия пунктов настроек зависят от версии ОС.
3. Откройте **`https://192.168.1.15:8765`**. Это адрес ПК при подготовке;
   актуальные адреса выводит скрипт запуска. Виртуальный адаптер
   `198.18.0.1` для домашнего Wi-Fi не используйте.
4. На странице ПК нажмите **Телефон**. На телефоне нажмите **Подключиться**
   и введите код. Он одноразовый, действует 24 часа.
5. Доступны текст, **Говорить**, **Прервать**, **Фото** и настройки моделей.
   Микрофон включается только по нажатию и с разрешением браузера.
   **Закончить запись** отправляет реплику; предел записи — 50 секунд.

Отпечаток SHA-256 CA:
`7c058df5f61270b2bdfc63815deaea1990d0ca2ab38dd54081f1f2fdb7d47e06`.

Системное доверие сертификату и брандмауэр автоматически не менялись.
Если Windows блокирует подключение, выполните из `D:\yui` в PowerShell
**от администратора**:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\enable-phone-firewall.ps1
```

Это разрешит только TCP 8765 для `yui-core.exe`, только в частной сети и из
локальной подсети. Порт 8766 доступен исключительно с ПК. При смене IP:

```powershell
.venv\Scripts\python.exe scripts\configure-local.py
powershell -ExecutionPolicy Bypass -File scripts\build.ps1
```

После этого перезапустите ядро. Конфигуратор сохраняет CA и существующий
конфиг, обновляя сертификат сервера. Для доступа вне дома нужна своя VPN
и сертификат с её адресом; публичный relay не реализован.

### Подготовленный доступ через Tailscale

На этом ПК настроен адрес **`https://100.110.162.100:8765`**.
Сертификат сервера обновлён для этого IP; корневой `Yui Local Command Center CA`
сохранён. Если он уже установлен и доверен на iPhone, повторная установка не нужна.
Правило Windows `Yui-iPhone-Tailscale-HTTPS` разрешает TCP 8765 только от
iPhone `100.72.64.30` на адрес ПК `100.110.162.100` через адаптер Tailscale.
Скрипт настройки: `scripts/enable-iphone-tailscale.ps1` (запуск от администратора).

1. Включите Tailscale на ПК и iPhone в одной сети Tailscale.
2. Откройте в Safari `https://100.110.162.100:8765`.
3. Если сертификат ещё не установлен, загрузите `/yui-ca.crt` с этого адреса
   либо перенесите публичный файл `data/tls/yui-ca.crt` на телефон.
   Установите профиль и включите полное доверие к нему в настройках iOS.
4. Получите свежий код кнопкой **Телефон** в интерфейсе ПК и введите его
   кнопкой **Подключиться** на телефоне. При смене адреса сайта Safari хранит
   отдельное сопряжение. Коды одноразовые, действуют 24 часа и сбрасываются
   при перезапуске ядра; уже выданные токены устройств сохраняются.
5. В Tailscale на iPhone: аватар → VPN On Demand → Wi-Fi: Always,
   Cellular: Always. Затем выключите Wi-Fi и проверьте диалог через LTE/5G.

ПК должен оставаться включённым, без сна, с интернетом и работающим Yui.
Для этого подключения не требуется Exit Node или проброс порта на роутере.
Если устройства переустановлены и получили другие IP, обновите сертификат
и адреса в правиле брандмауэра. Физическое открытие Safari и работа микрофона
через мобильную сеть требуют проверки на iPhone.

Официальные инструкции:
[VPN On Demand](https://tailscale.com/docs/features/client/ios-vpn-on-demand),
[доверие сертификату iOS](https://support.apple.com/ru-ru/102390).

## Установленные модели

| Назначение | Модель | Выполнение |
|---|---|---|
| Диалог | Qwen3.5-9B Q4_K_M | GPU / CPU |
| Игровой профиль | Qwen3.5-4B Q4_K_M | CPU |
| Зрение | mmproj-F16 для той же Qwen 9B | проектор CPU, LLM GPU |
| Поиск памяти | Qwen3-Embedding-0.6B, 256 измерений | CPU |
| Распознавание | faster-whisper-small, INT8 | CPU |
| Русский голос | Piper ru_RU-irina-medium, 22050 Гц | CPU |

Всего скачано 11,74 ГБ, включая архивы runtime. Точные размеры, ревизии
и SHA-256 весов — в `models/installed-manifest.json`.
`python scripts/download-models.py` проверяет файлы и докачивает недостающие.

Источники: [Qwen 9B](https://huggingface.co/unsloth/Qwen3.5-9B-GGUF),
[Qwen 4B](https://huggingface.co/unsloth/Qwen3.5-4B-GGUF),
[Qwen Embedding](https://huggingface.co/Qwen/Qwen3-Embedding-0.6B),
[Whisper small](https://huggingface.co/Systran/faster-whisper-small),
[Piper Irina](https://huggingface.co/rhasspy/piper-voices/tree/main/ru/ru_RU/irina/medium),
[llama.cpp b10819](https://github.com/ggml-org/llama.cpp/releases/tag/b10819).

Parakeet и CosyVoice из исходного README не установлены: для них в исходном
коде нет адаптеров. Здесь используются совместимый Whisper и добавленный
адаптер Piper. Отдельный тяжёлый VLM не нужен: зрение использует Qwen 9B.

## Проверки

```powershell
# Сборка и тесты Go, Python, TypeScript (остановите ядро перед пересборкой):
powershell -ExecutionPolicy Bypass -File scripts\build.ps1
# Реальные голос, распознавание и эмбеддинги:
.venv\Scripts\python.exe scripts\check-models.py
# Фоновый проверочный запуск:
.venv\Scripts\python.exe scripts\start-check.py
# Диалог, зрение, HTTPS-сопряжение и отзыв доступа:
.venv\Scripts\python.exe scripts\check-system.py
# WSS, полный голосовой путь, повторный GPU-запрос и 4B CPU:
$env:NODE_EXTRA_CA_CERTS = "$PWD\data\tls\yui-ca.crt"
node scripts\check-websocket.mjs
```

Отчёты — `artifacts/*.json`, голосовой пример — `artifacts/yui-voice-check.wav`.
Лог фонового центра — `.cache/core-check.log`, служебный токен —
`.cache/check-runtime.json` (не публикуйте этот файл).

## Что ещё не проверено или отсутствует

- Мобильная поддержка реализована в браузере. APK и Tauri-установщик не
  собирались; Go EXE и веб-интерфейс собраны.
- Компоновка проверена при 390×844. Физический телефон, микрофон, камера
  и брандмауэр требуют проверки на вашем устройстве. При сворачивании
  страницы микрофон выключается; фонового мобильного сервиса здесь нет.
- Live2D-модель и Cubism SDK отсутствуют в исходном проекте. Диалог работает
  с заглушкой аватара.
- Это сборка для проверки; тестовые реплики сохранены в `data/yui.db`.
  Пароль владельца не задавался, ключ шифрования не создавался.
  Полная интеграция шифрования остаётся отдельным пунктом исходного ROADMAP.
- `.venv` использует Python 3.12 из установленного runtime Codex. На другом
  ПК окружение нужно создать заново и установить `workers/requirements-local-lock.txt`;
  пути воркеров в конфиге также потребуется обновить.
