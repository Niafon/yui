# OpenRouter

Добавлены профили в `yui.config.json` и пример конфигурации. Клиент использует
совместимый OpenAI API, потоковые ответы и вызовы инструментов.

1. `OPENROUTER_API_KEY` сохранён как пользовательская переменная среды Windows
   22 сентября 2026. После переноса установки на другой компьютер задайте ключ
   заново для пользователя, запускающего ядро.
2. Перезапустите ядро и воркеры, обновите окно приложения.
3. В AI Runtime выберите нужную модель. Внешняя модель включает ручной режим
   и закрепляет конкретного провайдера; возврат к локальной модели снимает закрепление.
4. Разрешите запрашиваемые категории данных в существующем диалоге согласия.
   Профили допускают только текущий текст и сводку сессии; автоматический выбор
   остаётся локальным. Ключ не передаётся в браузер.

Проверенные 21 сентября 2026 года модели и цены за миллион входных / выходных
токенов (текущие предложения провайдеров, могут изменяться):

| Профиль | Модель | USD за 1M вход / выход |
| --- | --- | --- |
| openrouter-deepseek-flash | [DeepSeek V4.1 Flash](https://openrouter.ai/deepseek/deepseek-v4.1-flash) | 0.12 / 0.48 |
| openrouter-qwen-flash | [Qwen3.5 Flash](https://openrouter.ai/qwen/qwen3.5-flash-02-23) | 0.065 / 0.26 |
| openrouter-qwen-30b | [Qwen3 30B A3B Instruct 2507](https://openrouter.ai/qwen/qwen3-30b-a3b-instruct-2507) | 0.04815 / 0.1931 |

Тарифы не зашиты в алгоритм выбора. Любую другую модель можно добавить отдельным
профилем `driver: openai`, `local: false`, `auto_select: false` с точным ID из
каталога. [Официальная документация подключения](https://openrouter.ai/docs/quickstart).

Подключение DeepSeek V4.1 Flash проверено коротким запросом 22 сентября 2026.
При отсутствии ключа ошибка указывает имя переменной и необходимость перезапуска.
Ошибки внутри SSE-потока теперь также передаются пользователю.

## Исправление TTS

В журнале `core-launcher-error.log` Silero v5 ru падала в `process_simple_text`:
после нормализации фрагмента не оставалось произносимого русского текста,
а `ValueError` не содержал сообщения. Воркер теперь декодирует HTML-сущности,
нормализует ё и пропускает фрагменты без русских букв. Пустые исключения остальных
операций возвращают тип исключения и название операции.

Это русская озвучка: отдельные латинские слова, числа и эмодзи пропускаются,
а не переводятся и не транслитерируются. Для полноценной английской речи нужен
другой голос. Проверено на установленном `models/silero/v5_ru.pt`.
