`default.vrm` — базовая модель Avatar Orion (VRM 0.x) из репозитория
`madjin/vrm-samples`, добавленная только для локального демо и smoke-проверки.
Источник: https://github.com/madjin/vrm-samples

Модель распространяется по условиям CC0, указанным в README источника.
Для собственных моделей замените файл, сохранив имя `default.vrm`, и проверьте
встроенные условия лицензии модели.

Модель загружается только локально. Лицензия и условия распространения модели
должны быть указаны рядом с файлом владельцем ассета.

## Аниме-аватары

- `shino.vrm`: Sendagaya Shino, VRoid beta sample.
- `victoria.vrm`: Victoria Rubin, VRoid beta sample.

Источник: https://github.com/madjin/vrm-samples/tree/master/vroid/beta
Условия VRoid: https://vroid.pixiv.help/hc/en-us/articles/4402614652569
Оба файла без изменений, скачаны 2026-09-21. Встроенная VRM-метаинформация
обоих файлов указывает CC0, Everyone, commercial Allow.
Оба содержат привязанные формы рта a/i/u/e/o. Three-VRM преобразует a в aa.
Губы двигаются по распознанным гласным реально воспроизводимого звука
(wLipSync MFCC → формы aa/ih/ou/ee/oh) со сглаживанием. Новым пользователям по умолчанию выбрана Shino.
